Two-Body Gravity Simulator

1. Project Overview

This project is an interactive two-body gravity simulator that demonstrates the motion of two objects under their mutual gravitational attraction.

Both bodies revolve around their common centre of mass according to Newton's law of universal gravitation.

2. Features

- Adjustable masses of both bodies.
- Adjustable orbital eccentricity.
- Visualization of both orbital paths and trails.
- Centre of mass visualization.
- Adjustable simulation speed.
- Display of orbital and physical quantities.
- Pause and restart controls.

3. Technologies Used

- HTML
- CSS
- JavaScript
- Velocity-Verlet numerical integration method

4. Software Requirements

- A modern web browser such as Google Chrome, Microsoft Edge or Firefox.
- No separate software installation is required.

5. How to Run

1. Download "Two-Body Gravity Simulator.html" from this repository.
2. Open the downloaded HTML file in a web browser.
3. The interactive simulation will start.
4. Use the available sliders and controls to explore the two-body system.

6. Simulation Description

The simulation demonstrates how changing the masses affects the orbital radii of the two bodies. The heavier body follows a smaller orbit, while the lighter body follows a larger orbit around the common centre of mass.

The eccentricity control allows observation of different orbital shapes, from circular to elliptical orbits.
